# iHear Website

Static multi-page site for `ihearprogram.org`.

## Local Preview

```powershell
npm start
```

Open:

```text
http://localhost:4173
```

## Vercel

Use these settings:

- Framework Preset: `Other`
- Build Command: leave blank
- Output Directory: `.`
- Install Command: leave blank

The `vercel.json` file maps clean URLs such as `/team` to the matching HTML files.
