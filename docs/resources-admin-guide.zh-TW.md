# Resources 管理員操作說明

公開頁：https://www.ihearus.org/resources#resources  
管理後台：https://www.ihearus.org/admin/resources

以管理員帳號登入後，可從後台選擇「資源管理」，或在公開資源頁點「管理資源（表單／文章）」。一般訪客看不到管理入口。

## 新增表單或文章連結

1. 點「新增資源」。
2. 選擇「分類」：表單、報名與常用連結選「表單／常用連結」；外部文章選「文章」。填寫英文名稱；用途說明可留白，也可填文章摘要。名稱是網站顯示名稱，與來源網站的名稱分開。
3. 直接複製並貼上完整 HTTPS 網址，避免手打漏字。可先在新分頁開啟確認內容。
4. 填寫「顯示順序」，數字越小越前面，建議用 10、20、30，方便之後插入。
5. 填寫繁、簡中文，或保留「自動更新中文翻譯」並點「產生翻譯預覽」。確認三語文字正確。
6. 點「儲存草稿」可先保留而不公開；確定要上線時點「儲存並發布」。

如果直接點儲存，系統會先產生翻譯預覽；看到「預覽已完成」後，檢查文字並再次點儲存才算完成。修改文字後需重新預覽。

文章會列在獨立「文章」區，點擊後到來源網站閱讀全文。沒有已發布文章時，公開頁不顯示文章區。這一階段提供外部文章連結，沒有站內全文編輯、圖片上傳或影片嵌入。

## 修改名稱、用途或網址

在指定項目點「編輯」，修改後確認翻譯預覽並儲存。修改已發布資料時，選「儲存並發布」會維持公開；選「儲存草稿」則會將它隱藏。

中文未填時，訪客在中文頁面會看到英文備援。已人工修改的中文預設受到保護；只有希望重新翻譯取代人工內容時，才勾選「同時覆蓋人工修改的中文」。

## 排序、隱藏與復原

| 需求 | 操作 | 訪客看到的結果 |
|---|---|---|
| 調整位置 | 編輯「顯示順序」後儲存 | 數字小的排在前面 |
| 暫時不公開 | 點「隱藏」 | 從公開清單移除，後台保留草稿 |
| 重新公開 | 點「發布」 | 再次出現在公開清單 |
| 移除網站入口 | 點「移至回收區」並確認 | 從公開清單及管理中的清單移除 |
| 撤銷移除 | 到「回收區 → 資源連結」，點「復原」 | 恢復原本的發布或草稿狀態 |

移至回收區不會刪除 Google 表單。資源連結不提供永久刪除。其他頁面的報名按鈕也不會跟著改名或移除。

## 遇到提示時

- **載入失敗：**按「重新讀取已儲存資料」；公開頁可按「重新載入」。
- **其他管理員已更新：**先把仍需保留的草稿文字複製到自己的文件，再關閉編輯視窗、重新讀取資料，依最新內容修改。不要直接覆蓋對方的版本。
- **翻譯失敗：**可稍後重試，或取消自動翻譯並手動填寫中文，再產生預覽確認。
- **操作太頻繁：**依畫面提示等待後重試。

公開清單會在資料更新後刷新；切回該分頁或重新整理，也會讀取最新內容。
