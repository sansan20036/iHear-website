# 小老師卡片顯示模式

在 `/team` 的「小老師／Our Tutors」標題下方，訪客可以選擇：

- **全部收合**：保留頭像、姓名及職稱。
- **部分展開（摘要）**：預設模式，依序完整顯示學校、年級、橘色教學專長、簡短介紹，不限制行數；沒有簡短介紹時使用完整介紹。學校及年級仍遵守各自的公開設定，空欄位不顯示。
- **全部展開**：保留上述順序，再顯示使用語言、不同於簡介的完整介紹及興趣。

單張卡片的「查看完整介紹／收合為摘要」只控制該張卡片。點擊姓名列可收合卡片，再點擊則顯示摘要。頂部選項代表整區基底模式，不會隨個別操作改變高亮；重新選擇頂部模式會將所有卡片統一套用。

只有尚未顯示的使用語言、完整介紹或興趣，才顯示「查看完整介紹」。即使摘要很長，只要沒有其他內容就不顯示此按鈕，避免無效點擊。

切換模式使用原有卡片及頭像節點。語言切換、背景資料更新會保留當頁的模式與個別選擇；重新進入或重新整理頁面則恢復摘要模式，不寫入瀏覽器儲存或資料庫。核心團隊卡片維持原有展示。

管理員啟用「管理團隊檔案」後，編輯與排序按鈕在三種模式下均可使用。此功能不修改個人資料、照片或翻譯。

回歸測試位於 `tests/impact-admin.spec.mjs`，包含三語、320px／390px／桌面、短文／空白／長文、獨立展開、全區切換、重新載入、背景更新、鍵盤操作及頭像節點保留。
