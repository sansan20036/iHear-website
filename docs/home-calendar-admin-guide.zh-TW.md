# 首頁行事曆操作說明

首頁主視覺照片的右邊有一個活動行事曆。你在後台新增、修改或刪除活動，按「儲存」之後首頁會立刻更新；一般訪客只能查看，不能修改。

## 從哪裡進入

- **管理後台：** https://www.ihearus.org/admin/calendar ，也就是側邊欄的「首頁行事曆」。
- **從首頁進入：** 用管理員帳號登入後，首頁行事曆下方會出現「✎ 管理行事曆」。

## 新增活動

1. 按「新增活動」。
2. 填寫以下欄位：

   | 欄位 | 說明 |
   |---|---|
   | 活動名稱 | 必填，一行，最多 120 字 |
   | 日期 | 必填 |
   | 時間 | 填開始時間；結束時間可以不填。整天的活動請勾選「全天活動」 |
   | 說明 | 可不填，最多 1000 字，可以換行 |
   | 相關連結 | 可不填。要填完整網址，例如 `https://forms.gle/…`。「連結文字」也可以不填，不填時首頁會顯示「相關連結」 |

3. 按「儲存」。看到「已儲存，首頁已更新」就完成了。

## 完整的活動頁

首頁行事曆下方的「查看所有活動 →」會開啟 https://www.ihearus.org/events 。這一頁顯示同一份活動資料，可以切換三種方式：

- **月曆：** 活動名稱直接顯示在日期格裡。
- **活動清單：** 依月份列出即將到來的活動。
- **活動卡片：** 每個活動一張卡片。

手機上預設顯示活動清單。你在後台修改的活動，三種方式都會同時更新，不需要另外設定。

## 時間一律用台北時間

所有時間都請用**台北時間**填寫。首頁會顯示台北時間；訪客在其他時區時（例如美國），還會多顯示一行換算好的當地時間，你不需要另外換算。

## 修改、刪除

- **修改：** 在活動上按「修改」，改完按「儲存」。
- **刪除：** 按「刪除」，再按一次「確定刪除」。刪除後首頁會立刻移除這個活動。

已經過去的活動，會收在頁面下方的「已過去的活動」裡。行事曆最多可以放 200 個活動，太多時請刪除舊的活動。

## 活動內容的語言

活動名稱和說明只要填一種語言。不論訪客切換到英文、繁體或簡體，看到的都是你填寫的內容；只有按鈕、星期、月份這些介面文字會跟著切換。

## 遇到提示時

| 提示 | 怎麼處理 |
|---|---|
| 欄位下方出現紅字 | 依照提示修正後再按「儲存」 |
| 其他管理員剛更新了行事曆 | 你填的內容還在畫面上。先記下來，按「重新載入」，再重新修改並儲存 |
| 登入已過期 | 在新分頁重新登入，回來再按「儲存」 |
| 這個帳號目前沒有管理權限 | 請擁有者到「管理員」頁確認你的帳號 |
