# Academy 課程頁管理員操作說明

課程頁：`/academy/courses/zh`（繁體中文）、`/academy/courses`（英文）  
管理後台：`/admin/academy`（側邊欄「Academy 課程頁」）

以 Google 管理員帳號登入後才能編輯。一般訪客看不到任何編輯按鈕。修改方式有兩種，改的是同一份內容：

- **後台集中編輯：**在 `/admin/academy` 一次檢視全部價格與文字。
- **課程頁直接編輯：**登入後開啟課程頁，每個可編輯區塊旁會出現「✎ 編輯」，點選後只顯示該區塊的欄位。

## 修改價格

1. 在「課程價格」表格中輸入單堂價格，台幣與美元分別填寫，不會自動換算。
2. 只能輸入整數（例如 `1000`），不要加 `NT$`、逗號或小數點。台幣可填 1–100,000，美元可填 1–5,000。
3. 「十堂九折」金額由系統自動計算（單堂 × 10 × 90%），常見問題中的價格也會跟著更新，不需要另外修改。
4. 出現黃色提醒（例如 60 分鐘比 45 分鐘便宜）時，請再確認一次；提醒不會阻止發布。

## 修改文字

在「頁面文字」選擇「繁體中文頁面」或「英文頁面」，展開要修改的區塊。中文與英文分開儲存，修改其中一種語言不會影響另一種。常見問題的價格列表由系統產生，只能修改列表前後的文字。

導覽列、語言切換、Email 地址、幣別與方案名稱等由程式維護，不在可編輯範圍內。

## 預覽與發布

1. 點「預覽頁面」，在尚未發布的狀態下查看整頁效果，可切換中英文。
2. 點「檢查變更並發布」，確認變更前後的內容。
3. 點「確認發布」。看到「已發布」提示才算完成；訪客重新整理課程頁即可看到新內容。從課程頁的 ✎ 發布時，頁面會自動重新整理。

尚未發布前離開頁面、重新載入或關閉編輯視窗，系統都會先詢問，避免草稿遺失。

## 遇到提示時

| 提示 | 原因 | 處理方式 |
| --- | --- | --- |
| 欄位下方紅字 | 價格或文字格式不正確 | 依說明修正，修正前無法發布 |
| 另一位管理員已發布較新的版本 | 有人在你編輯期間先發布了 | 草稿仍保留；先記下要改的內容，按「重新載入最新內容」再修改發布 |
| 登入已過期 | Google 登入已失效 | 在新分頁重新登入，回來按「重新確認權限」，再發布 |
| 這個帳號目前沒有管理權限 | 帳號不是管理員或已被停用 | 請擁有者在「管理員」頁確認帳號 |
| 未能發布，草稿已保留 | 網路或伺服器暫時異常 | 稍後再按發布；不會只儲存一部分 |
