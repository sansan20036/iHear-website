## 管理流程試用

建議先用測試環境驗收發布、排序、隱藏和復原。若只在正式後台練習，可新增一筆明確命名的草稿，練習編輯、移至回收區及復原；保持草稿，不公開測試內容，也不要用既有三份正式表單作刪除練習。

- [ ] 新增後可儲存草稿，訪客看不到草稿。
- [ ] 能選擇「文章」分類，發布後會出現在文章區；隱藏最後一篇文章後，該區不再顯示。
- [ ] 可以修改網站顯示名稱，Google 表單原始名稱不受影響。
- [ ] 翻譯預覽容易理解，人工中文保持原值。
- [ ] 數字排序符合預期；不同管理員同時修改時會提示重新讀取。
- [ ] 發布／隱藏的結果符合預期，另一個公開頁分頁能看到更新。
- [ ] 移至回收區需確認，且能復原原狀態。
